# AI in the Real World — Interactive Lesson

Grade 9–10 case-study lesson (~10 slides): five industries where AI matters, then short group **AI consultant** briefings.

## Industries

- Healthcare
- Finance
- Education
- Transportation
- Military / Security

## Present

```bash
npm install
npm run dev
```

Press **F** for fullscreen.

| Key | Action |
| --- | --- |
| `→` / `Space` | Next |
| `←` | Back |
| `N` | Speaker notes |
| `F` | Fullscreen |

## Activity

Groups investigate one industry using six consultant questions, then deliver a 2-minute briefing.
